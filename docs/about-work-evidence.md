## Finding requiring a decision

The broad proposition “the first artwork in which an agent participates or contributes intention” is not supported by the evidence below. Earlier projects explicitly use autonomous systems, behavioral agents and, more recently, multi-agent LLM creative reasoning. This is an inference from selected primary sources, not an exhaustive priority search or a claim that the projects have identical mechanics.

Specificity describes the work; it does not by itself substantiate “first.” The referenced Agent Art definition at `https://inshell.art/docs/agent-art` could not be retrieved during this research, so no unseen definition is assumed.

## About outline and working copy

The following factual sections can be refined independently of the priority claim. They describe the implemented architecture, not proof that the live paid pilot has succeeded.

### The work

An X handle becomes a signature through an artist-defined visual system and Grok’s interpretation. The artist defines the renderer and its rules. Grok chooses an MBTI-inspired input from public X research. The collector chooses a handle and authorizes the mint. The first accepted assessment is preserved instead of being rerolled for a preferred result.

Agent contribution here means a model-selected artistic input within that system. It is not a claim of consciousness, objective psychological truth or a cryptographic signature issued by Grok. Signatures Gallery records the assessment and its backend authorizes the mint.

### Preview and mint

Preview is editable exploration at `/p/<handle>/<MBTI>`. It does not call the site's paid assessment service, require a wallet or confer mint authority. A Grok chat can suggest the preview; changing its URL is allowed.

Mint is a separate, explicit action on the site. The backend verifies the handle's current X spelling and requests its own Grok assessment, ignoring preview MBTI input. An accepted assessment and its artwork are saved before the wallet transaction. The site reveals the result after confirmation; this is a reveal experience, not cryptographic secrecy. Failure or insufficient evidence does not invent a result or silently retry.

### One handle, one token

Identity is the lowercase literal handle, not handle × MBTI or the X account ID. The exact verified spelling is a preparation snapshot. Renaming an X account does not rewrite an existing work; a different handle is a different token identity. Capitalization alone does not create another identity. A cancelled transaction, expired request or new session reuses the saved result.

### What provenance establishes

The collapsed record shows the saved assessor, model, assessment time, source links and any recorded preparation-time X identity, separately from renderer hashes and mint data. Links may later change or disappear. Missing historical fields stay missing; fixture inputs do not become Grok assessments. No rationale or confidence score is invented. The MBTI letters are conventional type labels used here as artistic inputs, not a questionnaire result or diagnosis.

The letter expansions were checked against the [Myers & Briggs Foundation overview](https://www.myersbriggs.org/my-mbti-personality-type/myers-briggs-overview/). This does not imply endorsement or psychological validation of Grok's interpretation.

### Ownership and permanence

No project mint fee; the minter pays network gas. Holding a token does not prove ownership or control of its X account. The public chain record is permanent; long-term artwork availability also depends on the storage/retention architecture. Public storage, public-chain deployment and operational guarantees must be described only after E16–E23 establish and verify them.
